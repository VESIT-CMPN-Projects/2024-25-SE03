# Posters Directory

This directory contains promotional posters and visual materials for the Parvarish NGO project.

## 📁 Directory Structure

```
posters/
├── README.md           # This file
├── events/            # Event promotion posters
├── programs/          # Program awareness posters
├── campaigns/         # Donation and awareness campaigns
└── social-media/      # Social media graphics
```

## 📋 Naming Convention

Use descriptive names for poster files:
- Format: `{type}-{name}-{date}.{ext}`
- Examples:
  - `event-annual-fundraiser-2024-03-15.png`
  - `program-education-initiative.pdf`
  - `campaign-donation-drive-q1-2024.jpg`
  - `social-instagram-post-volunteer.png`

## 📤 Adding New Posters

1. Create your poster using the [Canva template](https://www.canva.com/design/DAG_sETq7X0/bmX1D_oo3M2YzokU0g9W_g/edit)
2. Export in appropriate format (PNG for digital, PDF for print)
3. Place in relevant subdirectory
4. Update this README with a description of the poster
