## 🎯 Brand Guidelines

### Mission Statement
Parvarish is an NGO dedicated to supporting differently-abled children through education, healthcare, and sustainable development initiatives.

### Key Messages
When creating posters, emphasize:
- **Education** - Empowering through learning
- **Healthcare** - Supporting physical and mental well-being
- **Sustainability** - Building long-term solutions
- **Inclusivity** - Supporting differently-abled children
- **Community** - Building a supportive network

### Color Palette
Use colors that reflect warmth, hope, and professionalism:
- Primary colors should convey trust and compassion
- Maintain consistency with the website design
- Ensure accessibility with sufficient contrast ratios

### Typography
- Use clear, readable fonts
- Maintain hierarchy: Headline > Subheading > Body text
- Ensure text is legible at various sizes

## 🖼️ Poster Types

### 1. Event Promotion Posters
- Include event name, date, time, and location
- Add QR code for registration or more information
- Use engaging imagery related to the event

### 2. Program Awareness Posters
- Highlight specific programs (education, healthcare, etc.)
- Include success stories or testimonials
- Show impact statistics if available

### 3. Donation Campaign Posters
- Clear call-to-action for donations
- Include QR code for easy donation (reference: `frontend/src/assets/donation-qr.jpg`)
- Show how donations make a difference

### 4. Social Media Graphics
- Square format (1080x1080) for Instagram
- Landscape format (1200x630) for Facebook/Twitter
- Story format (1080x1920) for Instagram/Facebook stories

## 📋 Poster Creation Checklist

### Before You Start
- [ ] Identify the poster's purpose and target audience
- [ ] Gather necessary content (text, images, statistics)
- [ ] Review brand guidelines and existing designs
- [ ] Access the Canva template or Figma reference

### Design Elements
- [ ] Eye-catching headline
- [ ] Clear and concise body text
- [ ] High-quality images (available in `frontend/src/assets/`)
- [ ] Parvarish logo (located at `frontend/src/assets/logo.png`)
- [ ] Contact information or QR code
- [ ] Call-to-action (CTA)

### Final Checks
- [ ] Proofread all text for errors
- [ ] Verify all dates, times, and contact details
- [ ] Check color contrast for readability
- [ ] Ensure logo and branding are correct
- [ ] Test QR codes if included
- [ ] Export in appropriate formats (PNG, PDF, JPEG)

## 🛠️ How to Use the Canva Template

1. **Access the Template**
   - Click on the [Canva design link](https://www.canva.com/design/DAG_sETq7X0/bmX1D_oo3M2YzokU0g9W_g/edit)
   - Log in to your Canva account (or create one if needed)

2. **Make a Copy**
   - Click "File" → "Make a copy" to create your own editable version
   - This ensures the original template remains intact

3. **Customize Your Poster**
   - Replace placeholder text with your content
   - Update images from the project assets or use relevant photos
   - Adjust colors while maintaining brand consistency
   - Modify layout as needed for your specific use case

4. **Use Project Assets**
   - Logo: Use `frontend/src/assets/logo.png`
   - Hero image: Reference `frontend/src/assets/hero-bg.jpg`
   - Founder photo: Available at `frontend/src/assets/founder.png`
   - Donation QR: Use `frontend/src/assets/donation-qr.jpg`

5. **Export Your Design**
   - Click "Share" → "Download"
   - Choose format: PNG for digital use, PDF for print
   - Select quality settings based on final use

## 📤 Where to Save/Share Posters

### For Repository
- Save poster files in a new `posters/` directory in the root
- Use descriptive naming: `poster-{event/program}-{date}.png`
- Include source files (Canva links) in a `posters/README.md`

### For Printing
- Export as high-resolution PDF (300 DPI minimum)
- Use CMYK color mode for professional printing
- Include bleed area if required by printer

### For Digital Distribution
- Export as PNG or JPEG
- Optimize file size for web/social media
- Create multiple sizes for different platforms

## 🎓 Design Tips

### Visual Hierarchy
1. **Most Important**: Main headline and key visual
2. **Secondary**: Supporting information and CTA
3. **Tertiary**: Contact details and fine print

### Image Guidelines
- Use high-resolution images (minimum 300 DPI for print)
- Ensure images are relevant and emotionally engaging
- Respect copyright - use only authorized images
- Consider accessibility for all viewers

### Text Best Practices
- Keep headlines short and impactful (5-7 words)
- Use bullet points for multiple pieces of information
- Limit font types to 2-3 maximum
- Ensure sufficient white space around text

### Call-to-Action (CTA)
- Make CTAs clear and actionable
- Examples: "Donate Now", "Join Us", "Learn More", "Register Today"
- Use contrasting colors to make CTAs stand out
- Include a simple way to respond (QR code, URL, contact)
